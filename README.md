# Specify an Agentic Data Workflow

_Write the specification for a workflow combining data from multiple sources into a report, then use GitHub Copilot to create the report and validate the results. No programming required._

## Welcome

- **Who is this for**: Business analysts comfortable editing Markdown and navigating GitHub issues and pull requests.
- **What you'll learn**: Explain the report you need, write down the rules, ask Copilot to prepare it, and compare the result with the original data.
- **What you'll build**: Written reporting instructions (a specification), a program prepared by Copilot, the report files, and your completed review checklist.
- **Prerequisites**: A GitHub account with access to [Copilot coding agent](https://docs.github.com/en/copilot/concepts/agents/coding-agent/about-coding-agent), permission to run Actions, and basic GitHub editing and pull request skills. No programming is required.
- **How long**: Approximately 60-90 minutes, plus agent processing time.

In this exercise, you will:

1. Describe the report you need to create and explain the constraints.
1. Work out two expected results so that you can validate the output.
1. Assign an implementation issue to Copilot and inspect its pull request.
1. Compare the report with your expected results and record your decision before accepting the work.
